# x86 Bootloader: Real Mode to Protected Mode

This project is a simple x86 bootloader written in NASM Assembly. It demonstrates the fundamental steps required to boot a computer, initialize the environment in 16-bit Real Mode, and successfully transition the CPU into 32-bit Protected Mode.

## Features

  * **16-Bit Real Mode Initialization:** Sets up segment registers (DS, ES, SS) and the stack pointer.
  * **BIOS Interrupts:** Uses BIOS interrupt `0x10` to print text to the screen while in Real Mode.
  * **A20 Line Enable:** Enables the A20 address line to allow access to memory beyond 1 MB.
  * **Global Descriptor Table (GDT):** Defines a basic GDT with null, code, and data descriptors.
  * **Protected Mode Switch:** Switches the CPU CR0 register to enter 32-bit mode.
  * **VGA Memory Writing:** Writes directly to Video Memory (`0xB8000`) to print text in Protected Mode (since BIOS interrupts are no longer available).

## Prerequisites

To build and run this bootloader, you will need:

1.  **NASM** (Netwide Assembler) to compile the assembly code.
2.  **QEMU** (or Bochs/VirtualBox) to emulate the hardware and run the bootloader.
3.  **Make** (Required to use the build script).

### Installation (Linux/Debian)

```bash
sudo apt update
sudo apt install nasm qemu-system-x86 make
```

### Installation (macOS)

`` bash
brew install nasm qemu
```

## Build & Run Instructions

This project includes a `Makefile` to automate the build process. You can use the following commands in your terminal:

### Core Commands

| Command | Description |
| :--- | :--- |
| `make` | **Default.** Builds the binary, runs it in QEMU, and cleans up. |
| `make build` | Compiles `boot.asm` into `boot.bin`. |
| `make clean` | Removes generated binaries and log files. |

### Emulation Options

| Command | Description |
| :--- | :--- |
| `make run` | Runs the bootloader in QEMU. |
| `make run-noreboot` | Runs with `-no-reboot` (keeps window open on crash). |
| `make run-floppy` | Boots as a floppy disk (`-fda`) instead of a drive. |
| `make run-log` | Runs with CPU logging enabled (saves to `qemu.log`). |

### Debugging with GDB

1.  **Start the Debugger Host:**

    ```bash
    make debug
    ```

    *This starts QEMU in a paused state, waiting for a connection.*

2.  **Connect GDB:**
    Open a new terminal window and run:

    ```bash
    make gdb
    ```

    *This connects your local GDB to the running QEMU instance.*

## File Structure

  * `boot.asm`: The main assembly source code.
  * `boot.bin`: The compiled binary (generated by `make`).
  * `Makefile`: The build script (see below).

## Appendix: Makefile Source

For reference, this is the `Makefile` script used in this project:

```makefile
# Makefile — bootloader build & debug helpers
NASM  := nasm
QEMU  := qemu-system-x86_64
OUT   := boot.bin
ASM   := boot.asm

QEMU_OPTS      := -drive format=raw,file=$(OUT)
QEMU_NOREBOOT  := -drive format=raw,file=$(OUT) -no-reboot -serial stdio
QEMU_FLOPPY    := -fda $(OUT) -serial stdio

.PHONY: all build run run-noreboot run-floppy debug gdb run-log clean

# default: just build
all: build run clean 

build: $(ASM)
	$(NASM) -f bin $(ASM) -o $(OUT)

# normal run (boots, may auto-reboot on triple-fault)
run: $(OUT)
	$(QEMU) $(QEMU_OPTS)

# run but don't reboot on fault and attach serial to stdout (useful to see messages)
run-noreboot: $(OUT)
	$(QEMU) $(QEMU_NOREBOOT)

# boot as a floppy device (useful in some QEMU configs)
run-floppy: $(OUT)
	$(QEMU) $(QEMU_FLOPPY)

# run with logging to qemu.log (instructions + interrupts). Good for diagnosing faults.
run-log: $(OUT)
	$(QEMU) -d in_asm,int -D qemu.log $(QEMU_NOREBOOT)

# debug: start qemu halted and open gdb server on tcp/1234. Attach with gdb to step through.
debug: $(OUT)
	$(QEMU) -S -s $(QEMU_NOREBOOT)

# Start gdb connected to qemu (helper, needs gdb installed)
gdb:
	gdb -ex "target remote :1234"

clean:
	rm -f $(OUT) qemu.log
```
